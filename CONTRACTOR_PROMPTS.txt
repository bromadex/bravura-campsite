CONTRACT & CONTRACTOR MANAGEMENT (CL) MODULE — IMPLEMENTATION PLAN
═══════════════════════════════════════════════════════════════════════════════

Module code: CL   |   T-codes: CL01–CL11   |   Color: #0D7377 (deep teal)
Permission gates: contractors.view / contractors.edit

This module manages every external resource Bravura pays for: contractor
companies, casual workers, contractor employees, hired vehicles/equipment,
timesheets, and provides cross-module cost aggregation.

CROSS-MODULE INTEGRATION POINTS
───────────────────────────────────────────────────────────────────────────────

  HR       → employees.contractor_id links employees to companies
           → Supervisor assignment for timesheets
           → Shift definitions for casual worker schedules
  Campsite → room_assignments tracks contractor worker accommodation
  Meals    → meal entries track meals per employee (contractor-linked)
  Fuel     → fuel_transactions.fleet_asset_id links to hired vehicles
  Fleet    → fleet_assets linked via hired_vehicles/hired_equipment
  Safety   → (future) inductions, PPE tracking, incident reports
